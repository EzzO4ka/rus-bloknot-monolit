## 🏛 О проекте

**«Монолит»** — это интерактивный текстовый редактор, созданный по мотивам культового изометрического калькулятора «Монолит». Проект объединяет строгую эстетику кибер-патриотизма, палитру государственного триколора (Белый, Синий, Красный), векторную изометрию и бескомпромиссный дозор за культурой речи и верностью традициям.

Блокнот не просто сохраняет записи, но и стоит на страже чистоты языка: выявляет сквернословие, пресекает чужеродный сленг, защищает авторитет государства и напоминает о созидательном труде.

## ✨ Ключевые особенности

- 📐 **Изометрический дизайн**: Векторный логотип-монолит с устремлённой ввысь стрелой, цифровым экраном и клавишами в цветах флага РФ.
- 🛡️ **Интеллектуальный фильтр без ложных тревог**: Слова проверяются строго по завершении их набора (пробел, знак препинания, перевод строки). Слова вроде *«хлеб»* или *«употреблять»* не блокируются.
- 🚨 **Аудио-синтез сирены**: Тревожная сирена, колокольный благовест и победные фанфары синтезируются программно через Web Audio API без внешних аудиофайлов.
- 📂 **Организация помыслов**: Двухпанельный интерфейс с боковой летописью, системой папок и мгновенным поиском.
- 📱 **Готовность к смартфонам**: Умное разделение на мобильные вкладки истории и редактора с комфортными сенсорными зонами.

## 🚀 Полный каталог функциональности

### 1. Дозор Чистоты Речи
* **Анти-Мат**: Полное искоренение обсценной лексики, мата и оскорблений с моментальной заменой на благочестивые эвфемизмы (*«Благодать Божия»*, *«Святая Тишина»*, *«Праведное Деяние»*, *«Спаси Господи»*).
* **Искоренение чужебесия и сленга**: Автоматический перевод молодежного жаргона и англицизмов на классический русский слог:
  - *скуф* → «Муж зрелых лет»
  - *альтушка* → «Девица своенравная»
  - *сигма* → «Смиренный воин»
  - *вайб* → «Благорастворение воздухов»
  - *кринж* → «Срам душевный»
  - *дедлайн* → «Срок урочный»
  - *тильт* → «Минутное уныние»
* **Пресечение богоборчества**: Автоматическое устранение фраз отрицания веры (*«бога нет»*, *«бог выдумка»*) с заменой на исповедание: *«Бог есть Любовь и Творец Всего Сущего»*.
* **Обличение суеверий**: Замена упоминаний гороскопов, карт таро и астрологов на *«Промысел Всевышнего»* и *«Пустое гадание»*.
* **Канонические переключатели**: Возможность выборочно включать щиты («Без брани», «Без сленга», «Без гаданий», «Благоговение») в боковой панели.

### 2. Синтез Звука (Web Audio API)
* 🚨 **Тревожная Сирена**: Двухгенераторный синтезатор (sawtooth + triangle) с частотной модуляцией от 520 Гц до 925 Гц, создающий звук тревоги ГО при обнаружении нарушений. Сопровождается пульсирующей красной рамкой редактора.
* 🔔 **Колокольный Благовест**: 4-гармонический синтезатор церковного звона с плавным экспоненциальным затуханием длительностью 2.5 секунды.
* 🎺 **Победная Фанфара**: Мажорный арпеджио-аккорд в тональности До-мажор для наградных событий.

### 3. Сакральная нумерология и Пасхалки
* **Запретные числа**: Ввод чисел `67`, `52`, `1488`, `104`, `666` категорически блокируется, сопровождаясь сиреной и заменой на предостережение.
* **Награда за Код 777**: Набор комбинации `777` активирует торжественную фанфару и выводит окно награды:  
  *«Партия гордится тобой, ты выиграл святой приз от Александра невского, забери прямо сейчас»* со священным артефактом.

### 4. Система Государственного Контроля
* **Защита авторитета власти**: Пресечение оскорблений руководства страны и упоминания А. Навального.
* **«Партия не одобряет!»**: Попытка оскорбить руководство государства вызывает сирену и окно тревоги государственного контроля.
* **«Партия вас уважает!»**: При выражении патриотизма и верности Отечеству (*«Служу России»*, *«Слава России»*, *«Партия права»*) звучит фанфара и вручается знак партийного доверия.

### 5. Духовный модуль
* **Идеи помолиться Богу**: Модальное окно с тремя каноническими текстами:
  1. *Молитва Оптинских старцев на начало дня*
  2. *Молитва о защите Отечества и народа*
  3. *Благословение перед началом всякого труда*
  Тексты переносятся в блокнот одним кликом в сопровождении колокольного звона.
* **Священный Псалом 67**: Специальный раздел с текстом 67-го Псалма царя Давида (*«Да воскреснет Бог, и расточатся врази Его...»*) с возможностью быстрой цитаты.

### 6. Встроенный калькулятор «Монолит»
* Арифметический калькулятор в фирменной изометрической стилистике.
* Операции сложения, вычитания, умножения, деления, процентов и десятичных дробей.
* Проверочная клавиша **«№67»** для тестирования канонической бдительности.
* Кнопка **«Перенести результат в блокнот»** для мгновенной фиксации вычислений в тексте помысла.

### 7. Летопись помыслов, Папки и Поиск
* **Двухпанельный макет**: Слева — хроника записей, справа — полноразмерная рабочая зона редактора.
* **Система папок**: Включает папки по умолчанию (*«📁 Особая папка»*, *«📁 Священные мысли»*, *«📁 Дела Державные»*) и кнопку создания собственных директорий.
* **Мгновенный поиск**: Полнотекстовая фильтрация заметок по заголовкам и содержанию в реальном времени.
* **Телеметрия**: Подсчёт символов, слов, очищенных выражений и упоминаний числа 67.

### 8. Мобильная адаптация
* Адаптивное разделение интерфейса на мобильных устройствах через вкладки **«📜 История заметок»** и **«✏️ Редактор»**.
* Кнопка быстрого возврата `← Список` при редактировании со смартфона.
* Увеличенные сенсорные зоны (touch targets от 44px) для предотвращения случайных нажатий.

### 9. Постоянное сохранение данных
* Фоновое автосохранение с дебаунсом при наборе текста, смене полей и смене фокуса.
* Сохранение структуры папок и заметок в пользовательском профиле с защитой от случайного закрытия страницы.

## 🛠 Стек технологий

| Технология | Назначение |
| :--- | :--- |
| **HTML5 / Single-File Architecture** | Автономная сборка в один `.html` файл без внешних бандлеров |
| **Tailwind CSS** | Адаптивная тёмная тема в палитре государственного флага РФ |
| **Vanilla JavaScript (ES6+)** | Реактивная логика без применения тяжёлых фреймворков |
| **Web Audio API** | Программная генерация звуков тревожной сирены, колокола и фанфар |
| **Inline Vector SVG** | Изометрический монолит-логотип с динамической отрисовкой |

## 🚦 Установка и быстрый старт

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/monolith-patriot-notepad.git
   ```
2. Откройте файл `monolith_patriot_notepad.html` в любом современном браузере (Chrome, Yandex, Firefox, Safari, Edge).
3. Приложение не требует сборки через Node.js, `npm install` или сторонних серверов — всё работает автономно прямо из файла.
